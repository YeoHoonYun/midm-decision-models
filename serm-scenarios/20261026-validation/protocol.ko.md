# 36-R15 거시·산업·기업 시나리오와 검증

2026-10-26. 기존 결과를 알고 설계한 탐색적 후속 분석이다. 미접촉 확증 실험이나 금융 인과 추정으로 표현하지 않는다. 결과 확인 전 이 파일과 실행 코드를 해시로 동결한다. 기존 36-R14의 스냅숏·원문·실행 결과는 변경하지 않는다.

## 분석 계약

- 실제 보관 가격·수급·뉴스·공시만 사용한다. 합성 관측 없음. 10월26일 기업 리포트는 조건부 해석이며 미래 결과가 아직 없다.
- 거시 관측 → 산업 전달 조건 → 기업의 주체·자원 → 시나리오 전환을 연결한다. 산업별 서술은 가설이며 산업지수 수익률 검증으로 부르지 않는다.
- 상위10 기업은 시가총액 선정 범위, Top-N은 예측 후보 경로 수, 레짐은 입력 당시 환경이다.
- SER-M 이론의 적합성, 계산 구현, 비교 성능을 구분한다. P의 전략적 S/E/R 배열과 실행 의존성 그래프를 별도로 기록한다.

## 실제 경로 Top-N·학습 시드

정정 패널의 과거 실제 일별 종가로 ±5% 경계의 다섯 상호배타 경로(up_only/down_only/up_then_down/down_then_up/neither)를 만든다. 기준점은 익일 종가, 이후 5/10/20거래일이다. 08:30에 그 종가로 체결했다는 백테스트가 아니다. 원본 가격은 기업행동 조정이 보장되지 않는다.

평가 집합은 phase12의 20일 완전 관측 집합으로 고정하고, 모든 기간·방법·시드가 같은 행을 평가한다. 학습은 전체 정정 패널 중 입력 가용 조건과 경로 완결 조건을 충족하고 모든 경로 가격의 최초 보관시각이 첫 평가 결정시각보다 이른 행만 사용한다. 평가 날짜 5개마다 재학습, 최소 학습 날짜10개·행100개. 빈도 기준선, ExtraTrees 가격+미국, ExtraTrees 가격+미국+수급을 비교한다. 각각 64나무/min_samples_leaf=20/max_features=.8/bootstrap=False, 시드[361501,361502,361503,361504,361505]. 결과를 보고 설정을 바꾸지 않는다. 중위수 대체는 학습 자료로만 적합한다. 5시드 평균 확률의 순위와 각 시드의 순위를 모두 기록한다. 이 ML 비교는 SER-M 에이전트 우위 실험이 아니다.

Coverage@1..5, 각 경로 포착률, 양방향 도달 경로 누락률, 후보 집합의 시드 간 Jaccard, 시드별 평균·표준편차·범위, Brier 점수를 계산한다. N=5의 100%는 분류 규칙의 자명한 상한이다. 범주 포함률은 경로 모양·경제적 설명의 대표성이 아니다. 전체90% 및 관측 경로별80%를 탐색적 점검선으로 사용하되 보편적 기준이라 부르지 않는다. 날짜별 표본을 묶어 이동 블록(5/10개 관측 날짜), 5,000회 부트스트랩, seed=361500으로 구간을 계산한다. 블록10도 20거래일 중첩을 충분히 해결하지 못할 수 있고 표본 날짜가 짧아 구간은 민감도 참고용이다. 다중 탐색의 불확실성을 포괄하지 않으며 유의성 성공 판정은 하지 않는다.

현재 stock_list의 upName으로 산업별 기술 통계를 계산한다. 이는 과거 시점의 업종 분류를 재현한 것이 아니며 모델 입력이나 성과 기반 선정에 쓰지 않는다. 거시 그룹은 입력 sp500_ret<0, VIX>=20의 네 조합이다. 10월26일 상위10의 과거 부분집합은 생존·선정 편향이 있으므로 별도로 표시한다.

## 기존 정책 대응 구간

phase13 동일 21개 날짜의 SER-M C/T와 fixed_news/fixed_price_us/generic_context/제거조건 차이를 기존 selected_weight로 가중한다. 블록5/10, 5,000회, seed361500. 개별 주식일을 독립 표본으로 재표집하지 않는다. 기존 수치 재계산과 날짜 단위 불확실성 추가이지 새로운 정책 실험이 아니다.

## 로컬 생성 시드 파일럿

기존에 오류가 관측된 실제 KB금융·삼성생명 자료를 진단 목적으로 선택한다. 각 기업의 공식 반기 자본비율과 거시·산업·가격자료를 사용한다. 동일 Qwen3 4B, 입력, 두 호출 예산, max_tokens384, temperature=.6, top_p=.9, seed[361501,361502,361503]를 적용한다. 고정 분석→통합, 일반 적응 선택→통합, SER-M 목적·자원 적격성·의존성 제약 선택→통합을 비교한다. 총36호출; 실패 자동 재시도 없음. 출력 수치·기간·출처 ID·관측과 조건 구분 및 경로 집합 안정성을 검사한다. SER-M의 명시적 검증 게이트는 별도 기록하며 원시 모델 정확도에 섞지 않는다. 알려진 두 오류 사례의 진단이므로 전체 기업·에이전트 성능으로 일반화하지 않는다. 실제 도구 재수집이나 전략적 P 6배열 전체 실험은 이번 호출 비교에 포함하지 않는다. CPU 자체 프로세스만 쓰며 기존 GPU 작업에 개입하지 않는다.
