Method & audit

SER-M을 리포트에 적용한 방식

목적은 향후 5~20거래일에 판단을 바꿀 조건을 찾는 것입니다. 사실을 역할별로 검토하고, 충돌하는 증거와 추가 조회 조건을 남깁니다. 개인별 투자 성향이나 매매 권한은 부여하지 않았습니다.

S

주체

투자자·경영진·고객의 관찰 가능한 행동. 의도는 확인 가능한 진술이 없으면 추정으로 남깁니다.

E

환경

한·미 증시, 환율과 산업·제도 조건. 시점과 적용 범위가 다른 변수를 구분합니다.

R

자원

기업의 자금·생산·규제자본과 분석 도구의 자원을 구분합니다. 별도·연결 재무를 섞지 않습니다.

M

메커니즘

요소가 어떤 순서와 조건으로 연결되는지 가설을 만들고, 반증과 보류 조건을 지정합니다.

C / 조합

적격한 근거만 결합

직접 확인한 공시·기업 발표는 사실 근거, 수급은 관측, 제목 메타는 탐색 단서로 사용했습니다. 같은 뉴스의 반복을 독립 증거로 세지 않습니다.

P / 순서

실제 출력의 전달과 선택적 갱신

N/S → E → R → M 순서로 호출했습니다. E·R이 이전 역할을 단순 복사했는지와 자기 근거를 사용했는지를 별도로 대조했습니다.

T / 타이밍

재조회와 판단 보류

가격 충돌 9건의 과거 일별 시세와 금융·보험 2개사의 공식 PDF를 추가 조회했습니다. 새 근거로 R/M을 다시 호출합니다. 미래 시장 이벤트의 자동 추적은 아직 실행하지 않았습니다.

여기서 C/P/T는 조합·순서·타이밍을 뜻합니다. 사용자 선호를 추정하거나 누적전망이론의 손실회피 계수를 보정한 실행은 아닙니다.

Weights & confidence

가중치와 신뢰도의 적용 범위

근거의 우선순위는 질적으로 적용

동일 시점·대상에 직접 대응하는 공식 수치 → 날짜가 명확한 거래 관측 → 제목 메타 순으로 사용 범위를 제한했습니다. 충돌 시 평균이나 다수결로 덮지 않고 결론을 보류했습니다.

이는 학습된 수치 가중치가 아닙니다. 에이전트의 과거 적중률로 추정한 신뢰도, 사용자 가치 가중치, 계산 자원 배분 가중치를 서로 혼합하지 않았습니다.

신뢰도는 성공 확률과 다름

① 출처·시점 적격성 ② 주장과 근거의 대응 ③ 과거 성과 보정 여부 ④ 증거 간 의존성을 따로 봤습니다. 이번 실행에는 종목별 사후 성과와 보정된 확률이 없습니다.

같은 4B 모델을 공유하는 5개 역할은 서로 독립인 전문가 5명의 합의가 아닙니다. 따라서 “5명이 동의했으니 100%” 같은 수치를 제시하지 않습니다.

양쪽 미도달

검토기간 내 어느 종가 경계에도 미도달.

장중 스냅숏 가격을 기준으로 ±5% 경계를 정합니다. 다음 거래일부터 5·10·20개의 일별 종가를 각각 평가할 때, 상방만·하방만·양쪽(상방 선행)·양쪽(하방 선행)·둘 다 미도달 중 하나로 분류됩니다. 일별 종가 하나가 서로 다른 두 경계에 동시에 도달할 수는 없습니다.

한 기간에 경계를 여러 번 오가더라도 첫 도달 순서로 양쪽 경로를 분류합니다. 장중 고가·저가의 순서, 배당 재투자 총수익, 거래비용은 이번 계약에 없습니다. 권리락·주식분할 발생 시 조정 전후 가격을 그대로 연결하면 안 됩니다.

따라서 이 다섯 분류의 논리적 완전성은 정의에서 나옵니다. Top-N 후보가 실제 결과 대부분을 포함하는지, 여러 산업의 경제적 메커니즘을 대표하는지는 별도 표본과 미래 결과가 필요합니다. 이번 보고서에서는 그 포착률을 계산하지 않았습니다.

Execution audit

실제로 실행한 것과 검토 결과

10개 기업 × 5개 역할

Qwen3 4B Instruct, CPU 전용, 별도 문맥의 N/S/E/R/M 호출. 최종 실행에서 50개 역할 출력의 형식·출처 ID를 확인했습니다. 후속 자료 보강으로 R/M을 추가 4회 호출해 최종적으로 54개 역할 출력을 확인했습니다. 원 요청·응답과 입력 해시는 로컬 연구 폴더에 보존했습니다.

출력 길이와 출처 ID가 맞는 것만으로 사실성이 확인되지는 않습니다. 초기 50회에 대한 의미 검토에서 39개 역할 초안을 그대로 사용하지 않았습니다. 공개 본문은 이 모델 초안과 실제 자료를 다시 대조하여 Codex가 편집한 조건부 분석입니다.

실행 실패·보완도 보존

첫 실행은 JSON 형식 검증 라이브러리 누락으로 중단했습니다. 다음 시도는 메모리 사전 점검에서 종료됐습니다. 실패 기록을 남기고, 내장 형식 검사 및 축소 문맥·메모리 감시를 적용한 별도 실행을 수행했습니다.

다른 GPU 작업은 중단하지 않았습니다. 이번에 새 LoRA를 학습하거나 최고 성능 모델 비교를 실시한 것은 아닙니다. 일반 팀 대비 예측·수익·의사결정 개선 효과는 아직 검증하지 않았습니다.

후속 호출도 원문 대조가 필요했습니다KB금융 R은 반기 CET1 13.74%(E)를 보존했습니다. 삼성생명 R은 총자본 K-ICS 208%를 18%로 잘못 출력했고, M도 이 초안의 방향 판단을 이어받았습니다. 이 두 출력은 배제했으며 공개 리포트의 208%·177%는 공식 PDF 표를 직접 대조해 반영했습니다. 추가 조회의 성공과 모델의 해석 정확도는 서로 다른 결과입니다. 모델이 선택한 단일 경로를 검증된 Top-N으로 채택하지 않았습니다.
