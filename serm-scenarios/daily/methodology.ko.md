# 36-R29 일일 SER-M → CPT → WS 분석 계약

사용자 정의를 적용한 방법론 버전 1.1, 2026-10-27. 앞선 자료 조회 실행 제어를 기업 전략 방법론 전체와 동일시한 표현을 정정한다. 사용자 문장의 CBT 표기는 이어서 정의한 C/P/T를 기준으로 구현한다.

v1.1 정정: 실적·일정·가치평가 수치를 S에 자동 할당하지 않는다. 명시적 전략·자본배분 결정의 원문을 확인한 경우에만 S 근거로 연결하며, 회사의 발표 사실과 실제 이행·직원 동기·성과를 구분한다. 최초 원문6건은 AI 보조로 검토했다. 별도의 독립 인간 판정은 아니다. 확인한 주체 진술은20기업 중6기업이며14기업은 미확보다.

기업별 목적·외부 조건·자원 제약·결과 지표는 분석자가 설정한 검토 질문이다. 조건부 단계 확대와 자원 보전이라는 두 조합을 비교하고 환경 주도·자원 주도·전략 주도라는 세 후보 순서를 표시한다. 경로가 실증 선택되었다고 표시하지 않는다. 이는 모든 가능한 조합·순열의 포괄 검증이 아니다.

기업별 W 결정은 목적·선호·제약의 근거가 부족해 보류한다. 아래 v1 수치는 비교를 위한 참고 정책값으로만 남긴다. WS의 실행 순서는 W의 내림차순으로 결정하지 않는다. 환경 조건과 자원 가용성은 병행 확인할 수 있으며, 두 확인을 선행 조건으로 경영 승인, 단계 투입, 성과 재검토를 연결한다. 실제 집행 사실이 없는 과제는 제안 상태다.

T에서 검토일, 공시된 이벤트의 날짜 정밀도, 실제 적용 시점·속도·성과 시차를 구분한다. 예를 들어 월 단위로 발표된 계획을 임의의 일자로 바꾸지 않는다. 실제 시작일과 효과 시차를 확인하지 못하면 미확정으로 남긴다. 방법론 정정 시 기존 가격·뉴스를 재사용하면 원 수집일을 유지하고 원 발행판과 정정판을 모두 보존한다.

## 기업 분석 층

S(Subject)는 경영자의 의지·비전과 조직 구성원의 동기·실행 책임이다. 거래량, 투자자 순매매, 주가로 경영진 의지나 직원 동기를 추정하지 않는다. 발표된 계획·자본배분·조직 자료를 찾고 미확보 항목을 표시한다.

E(Environment)는 시장·수요·경쟁·정책·규제 등 외부 환경이다. 시장가격 지표는 그 일부이며 정책·경쟁 자료를 대체하지 않는다.

R(Resource)는 자본·인재·기술·생산능력 등 기업 자원이다. 자산·부채는 자원의 일부이며 별도/연결, 통화, 기간을 맞춘다. 서로 다른 지표를 기업 전체 역량 점수로 합산하지 않는다.

M(Mechanism)은 S/E/R의 조합이 성과로 이어지는 전략적 연결 가설이다. 관측 사실, 연결 가설, 반증 조건을 분리한다.

## CPT 설계 층

- C(Combination): S의 의사결정, E의 제약·기회, R의 투입을 어떤 구성과 상호 보완 관계로 결합할지 제시한다. 단순 자료 선택과 동일하지 않다. 구성의 상대적 중점은 연결된 WS 제안에서 명시한다.
- P(Permutation/Sequence): S/E/R 상호작용의 동적 순서와 인과 가설을 단계·화살표·검증 조건으로 명시한다. 자료를 읽는 순서와 구별한다. 역인과·공통요인 가능성도 남긴다.
- T(Time): 전략 적용의 조건부 타이밍, 실행 속도, 5/10/20거래일 모니터링과 중기 성과 관찰 시점을 구분한다. 공시일이 미확인되면 임의 날짜를 만들지 않는다. 재조회는 이를 지원하는 운영 수단이다.

## WS 실행 층

- W(Weight): S/E/R 집중 비중을 합계 1로 표시하고 목적·규칙 버전·적용일·근거를 붙인다. 이번 v1은 사전에 명시한 분석자 제안 규칙이며 학습된 최적값·기업 실제 예산·예측 확률·인과 기여도·경영진 선호가 아니다.
- S(Sequence): 가중치가 있는 전략 과제를 담당 주체·선행 과제·검토 기한·완료 조건으로 연결한 제안 로드맵이다. 기업이 실제 집행 중이라고 표현하지 않는다.

우선순위 규칙 v1: 지수의 20거래일 변화가 −5% 이하 또는 연율화20일 변동성30% 이상이면 방어 검토 S20/E50/R30. 그 외 지수20일 변화가 +3% 이상이고 변동성25% 미만이면 역량 확장 검토 S30/E25/R45. 나머지는 실행 정합성 검토 S40/E30/R30. 임계값은 이번 운영 예시의 사전 규칙이며 최적화·성능 검증된 레짐 분류가 아니다. 각 요소 ±10%p 변경 후 나머지 비례 재분배의 6개 민감도 조건에서 1순위 변화도 표시한다. 자료가 없다는 이유로 해당 요소 가중치를 0으로 만들지 않는다.

## 지원 시스템 층

자료 조회·출처 검증·시점 통제·보고/보류는 위 분석을 지원하는 별도 에이전트 실행 제어다. R24/R27은 이 제한된 지원 기능의 실험이며 완성된 SER-M/CPT/WS 기업 전략 효과의 검증이 아니다. 기존 실험과 원고 동결 파일은 변경하지 않는다.

## 주간 갱신·자료 기준일

한국10기업은10월26일 선정군을 추적하며 매일 시총 재선정하지 않는다. 미국10기업은 명시한 대표 추적군으로 현재 전체시장 시총 상위10 인증이 아니다. KOSPI/S&P500은 E의 시장 문맥이며 지수 자체를 기업 경영진으로 의인화하지 않는다.

완료된 거래일만 사용한다. XKRX/XNYS 일정의 최근 마감 세션과 일별 가격 날짜가 일치해야 최신 가격으로 발행한다. 미국 시간대는 America/New_York로 처리해 DST를 반영한다. 휴장일에는 동일 보고서를 새 관측으로 재발행하지 않는다. 자료 지연·수집 실패 시 마지막 유효판을 유지하고 상태 기록만 남긴다. 공시·전략 자료는 가격과 다른 기준일을 표시하며 자동으로 최신이라고 바꾸지 않는다.

한국 가격은 Naver 일별 차트, 미국 가격은 Yahoo 일별 차트를 사용한다. 미국 최신 완료 종가가 비어 있으면 Naver 해외 종가와 직전 공통 3거래일을 비교하고 차이가 각각 0.05% 미만일 때만 해당 종가를 보완한다. 두 원천의 URL·수집 시각·SHA-256과 차이를 기록한다. 서로 다른 가격 조정 기준이나 종목 매핑이 의심되면 발행을 보류한다. 원천의 Close 기술통계이며 배당 재투자 총수익률이 아니다.

공개 페이지에는 집계와 방법론 결과만 사용한다. 원시 가격 시계열, 로컬 경로, 비공개 입력, 인증 정보는 게시하지 않는다. 뉴스 제목만 읽었으면 제목 확인으로 표시하며 본문에서 확인한 사실로 전용하지 않는다. 인적 동기·비전이 미확보되면 미확보 상태를 유지한다.

기존 일일 시나리오의 한국18:30/미국09:00 KST 운영을 확인했다. SER-M 갱신은 한국 금요일19:15, 미국 토요일09:45 KST에 별도 실행한다. 2026-10-31부터 Windows 작업 스케줄러의 배치로 실행하며 PC 켜짐과 사용자 로그인이 필요하다. 채팅 heartbeat는 중지했고 로그만 남긴다. 실제 휴장·마감·지연 판정은 달력과 자료 검사가 담당한다. 이메일 전송·매매·기존 작업 중단은 실행하지 않는다.

최초 구현의 일일 분석은 명시적 규칙과 출처 대조를 이용한 구조화 분석이다. 실제 로컬 모델 신규 호출을 하지 않은 날에는 모델/에이전트 추론을 했다고 표시하지 않는다. 실증 검증 결과는 기존 연구 링크로 분리하고 새 일일 전망의 검증 성적으로 사용하지 않는다.

2026-10-28 사용자 요청: 시장별 주1회 갱신으로 전환했다. 최신 완료 거래일의 일별 가격과 원 공시일을 유지한다. 주간 발행을 주봉 예측·일별 전체 검증으로 바꾸어 해석하지 않는다. 기존 daily URL은 유지한다.
