02 / RECORDED EXECUTION

‘통합’ 전에 ‘조회’가 필요했던 순간.

36-R24의 실제 로컬 모델 출력과 실행 기록을 재생합니다. 화면을 바꿔도 새 모델 호출이나 외부 자료 수집은 실행하지 않습니다.

C / 조합 · P / 순서 · T / 조회·보류 전환

C는 필수 적격 자료를 포함하고, P는 검증 뒤 통합하도록 순서를 제어하며, T는 자료가 부족하면 조회하거나 보류합니다. 이 페이지의 C/P/T는 누적전망이론(CPT)을 뜻하지 않습니다. 동일 규칙의 일반 실행기도 같은 성공률을 보였으므로 이 효과를 SER-M만의 고유 우위로 귀속하지 않습니다.
