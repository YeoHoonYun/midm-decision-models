기존 보고서의 시장 브리프 → 케이스 설명 → 비교 표·차트 → 모델 출처 → 연구 부록 순서를 유지했습니다. 이번 공개판에는 원시 가격, 일자별 모델 확률, 비공개 생성문을 포함하지 않습니다.

선행지수는 경기 전환의 참고 지표, 제조업 생산은 실물 활동의 참고 지표, 실업률은 노동시장 반응의 참고 지표로 구분합니다. 이 수치를 곧바로 오늘 코스피 상승 확률로 바꾸지 않습니다.

MiDM 점수는 선행지수 변화와 같은 달에 움직이는 모습이 있었지만, 모델 자체의 경기 선행성은 입증되지 않았습니다. 결합 점수와 4개월 뒤 제조업 증가율의 상관은 약 0.51이었고 시차 탐색 검정 p=0.36으로 유의하지 않았습니다.

케이스별 시나리오와 대응 관점

현재 시점의 케이스 순위·확률·매수가·손절가는 새로 산출하지 않았습니다. 아래는 학습·보고서에서 사용하는 경로 정의와 해석입니다.

케이스경로해석
RT1초기 상방 도달·상승 유지상방 기준 도달 뒤 큰 되돌림이 없는 경로. 현재 확률과 신규 진입 신호는 미산출.
RT2초기 상승 후 되돌림상방 도달 뒤 큰 되돌림이 발생하는 경로. 이익 보호 조건을 점검할 대상.
RT3지연된 상방 도달첫 지평 이후 두 번째 지평 안에서 상방 기준에 도달하는 경로. 시간 조건을 분리해야 함.
RT4상방보다 하방 먼저 도달상방 기준보다 하방 기준에 먼저 도달하는 경로. 손실 제한 조건 검토 대상.
RT5하방 지속하방만 도달하고 종료 시점도 하방 기준 이하인 경로. 회복을 단정하지 않음.
RT6양방향 변동양쪽 기준 도달과 반복 방향 전환을 포함하는 경로. 단순 하락 분류가 아님.
RT7잔여 경로다른 규칙에 해당하지 않는 결과 유형. 관망·보류 행동과 동일하지 않음.
