## 반드시 유지할 구분

1. A01의 paired80은 80일 블록이며 95% 분위수 구간이다. 다중비교 보정 전 기술적 구간이다.
2. A05의 paired p는 3,000회 studentized stationary bootstrap 결과다. 공식 Ledoit–Wolf 구현을 재현했다고 표기하지 않는다. DSR은 가용 정책 분산을 대용한 N50/N412 민감도이며, 전체 시행 기반 DSR 및 CSCV-PBO는 미완이다. 정밀 집계에 희소 정책의 퇴화 재표집 횟수와 추론 상태를 보존했다.
3. A03의 2020·2022년은 학습 중첩 stress이며 holdout이 아니다. 2008/09는 이후 학습한 고정10특징 모델의 역방향 진단이며 당시 투자 가능한 예측 재현이 아니다.
4. A04 마스킹은 완료됐지만 look-ahead 통제 충족이나 사전학습 오염 부재를 입증하지 않는다. 해당 위험은 미해결이다.
5. A10은 2023 선택·보정 재사용 진단이며 보장된 conformal coverage가 아니다. 커버리지와 평균 집합 크기를 함께 비교한다.
6. REVIEW_KO.md는 추가 실험 실행 이전 원고 검토 원문이다. 그 안의 미실행 문구는 당시 상태다. 최신 실험 상태는 이 문서와 결과표를 따른다. 사용자 원고 파일 자체는 포함하지 않았다.
